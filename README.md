## 📖 Topics I Learned

### 1️⃣ Difference Between C/C++ and Java

* C/C++ are platform dependent.
* Programs compiled in C/C++ run only on specific systems.
* Java is platform independent.
* Java follows the concept: **Write Once, Run Anywhere (WORA).**

---

### 2️⃣ Platform Dependent vs Platform Independent

**Platform Dependent:**

* Code must be compiled separately for each operating system.
* Example: C, C++

**Platform Independent:**

* Code can run on any system without modification.
* Example: Java

---

### 3️⃣ Java Execution Process

Understanding how Java code runs:

```
Source Code (.java)
        ↓
   Java Compiler (javac)
        ↓
   Bytecode (.class)
        ↓
      JVM
        ↓
   Machine Code
        ↓
     Output
```

---

### 4️⃣ Bytecode

* Java compiler converts source code into bytecode.
* Bytecode is not machine code.
* It can run on any system using JVM.
* This makes Java platform independent.

---

### 5️⃣ JVM (Java Virtual Machine)

* JVM executes the bytecode.
* Converts bytecode into machine language.
* Different systems have different JVMs.
* JVM makes Java portable and secure.

---

### 6️⃣ ISA (Instruction Set Architecture)

* CPU understands only machine instructions.
* ISA defines how software communicates with hardware.
* Java uses JVM to handle this interaction.

---

### 7️⃣ Java Security (Sandbox Model)

* Java runs programs inside a protected environment.
* Prevents harmful access to system memory.
* No pointers (unlike C/C++).
* Automatic memory management.

---

## 🎯 Key Concepts to Remember

* Java is platform independent.
* JVM is platform dependent.
* Bytecode is platform independent.
* WORA = Write Once Run Anywhere.
